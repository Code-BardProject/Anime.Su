# Anime Catalog Web App

Веб-приложение в стиле аниме-портала: главный экран, каталог, страницы аниме, расписание, новости, профиль и админ-панель. Проект собран на React + Vite + TypeScript + Tailwind CSS.

## Что внутри

- Главная страница с карточками аниме, новостями и блоками рекомендаций
- Каталог с фильтрацией и просмотром карточек
- Страница аниме с детальной информацией
- Расписание релизов и событий
- Новости и статьи
- Личный кабинет пользователя
- Админ-панель для управления контентом
- Готовая структура под дальнейшую интеграцию с API и backend

## Технологический стек

- React 19
- React DOM 19
- TypeScript 5.7
- Vite 8
- Tailwind CSS 4
- @vitejs/plugin-react
- oxfmt

## Требования

Перед запуском убедитесь, что у вас установлены:

- Node.js 22+
- pnpm 10+
- Git

Проверить версии можно командой:

```bash
node -v
pnpm -v
```

## Установка

В корне проекта:

```bash
pnpm install
```

Если вы используете npm вместо pnpm, можно установить зависимости так:

```bash
npm install
```

## Запуск проекта

### Режим разработки

```bash
pnpm dev
```

или

```bash
npm run dev
```

По умолчанию Vite запускается на:

- http://localhost:8443
- или на порту из переменной `PORT`

### Запуск production preview

```bash
pnpm build
pnpm preview
```

## Доступные команды

```bash
pnpm dev       # запуск Vite в режиме разработки
pnpm start     # тот же запуск, что и dev
pnpm build     # сборка production-билда
pnpm preview   # локальный preview собранного проекта
pnpm format    # форматирование кода через oxfmt
```

## Переменные окружения

Основной проект использует стандартные настройки Vite. Важно учитывать, что в файле конфигурации есть поддержка переменных:

- `PORT` — порт запуска сервера
- `FIGMA_PUBLIC_URL` — базовый URL под деплой

Пример:

```bash
PORT=8443
FIGMA_PUBLIC_URL=https://example.com
```

## Основные директории

### src/

Содержит основное веб-приложение:

- `App.tsx` — корневой компонент и маршрутизация между страницами
- `components/` — UI-компоненты: navbar, карточки, секции, etc.
- `pages/` — страницы приложения
- `data/` — моковые данные
- `context/` — контекст приложения, например авторизация

### mobile/

Папка с отдельным мобильным приложением/экспериментальной частью проекта. Она не совпадает с основной веб-частью и может использовать собственные зависимости и настройки.

## Что важно знать

- Проект использует Tailwind CSS v4 через плагин `@tailwindcss/vite`
